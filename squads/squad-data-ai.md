## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                   SQUAD DATA & AI - WORKFLOW                      │
│                                                                   │
│  FASE 1: DESCOBERTA & ESTRATÉGIA                                 │
│  ├── Trend Researcher → Análise de tendências e SOTA             │
│  ├── AI Engineer → Definição de abordagem e arquitetura          │
│  ├── Data Engineer → Auditoria de fontes de dados                │
│  └── Analytics Reporter → Definição de métricas de sucesso       │
│                                                                   │
│  FASE 2: PIPELINE DE DADOS                                       │
│  ├── Data Engineer → ETL/ELT pipelines + data warehouse          │
│  ├── Data Remediation → Limpeza e qualidade dos dados            │
│  ├── Data Consolidation → Integração de múltiplas fontes         │
│  └── Backend Architect → APIs de dados + data serving layer      │
│                                                                   │
│  FASE 3: MODELAGEM & TREINAMENTO                                 │
│  ├── AI Engineer → Desenvolvimento e fine-tuning de modelos      │
│  ├── Model QA Specialist → Avaliação + testes de bias            │
│  ├── Analytics Reporter → Monitoramento de performance           │
│  └── Trend Researcher → Benchmarking com SOTA                    │
│                                                                   │
│  FASE 4: DEPLOY & OPERAÇÃO (MLOps)                               │
│  ├── DevOps Automator → CI/CD + model registry + serving         │
│  ├── AI Engineer → A/B testing de modelos                        │
│  ├── Model QA Specialist → Drift detection + retraining triggers │
│  └── Analytics Reporter → Dashboards de produção + alertas       │
│                                                                   │
│  ◆ Loop MLOps: Dados → Treinar → Avaliar → Deploy → Monitorar   │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Data & AI. Preciso construir um sistema de
recomendação personalizado para um e-commerce com 10M de usuários.

Comece pela Fase 1: o Trend Researcher deve mapear as abordagens
SOTA para sistemas de recomendação, o AI Engineer deve definir a
arquitetura (collaborative filtering, content-based ou híbrido) e
o Data Engineer deve auditar os dados disponíveis (logs de cliques,
histórico de compras, catálogo de produtos).
```

## 📊 Métricas de Sucesso

| Métrica | Target |
|---------|--------|
| Data pipeline latency | < 5 minutos (near real-time) |
| Data quality score | > 95% |
| Model accuracy (domínio-específico) | Definido por projeto |
| Model serving latency (P95) | < 100ms |
| Pipeline uptime | > 99.9% |
| Model drift detection | < 24h para alertar |
