## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                  SQUAD MARKETING - WORKFLOW                       │
│                                                                   │
│  FASE 1: ESTRATÉGIA & PLANEJAMENTO                               │
│  ├── Growth Hacker → Estratégia de crescimento + viral loops     │
│  ├── SEO Specialist → Audit SEO + keyword research               │
│  ├── Brand Guardian → Guidelines de marca + tom de voz           │
│  └── Social Media Strategist → Plano multi-canal                 │
│                                                                   │
│  FASE 2: CRIAÇÃO DE CONTEÚDO                                     │
│  ├── Content Creator → Editorial calendar + conteúdo             │
│  ├── Visual Storyteller → Assets visuais                         │
│  ├── Image Prompt Engineer → Imagens AI-generated                │
│  └── Carousel Engine → Conteúdo carrossel automático             │
│                                                                   │
│  FASE 3: DISTRIBUIÇÃO (Paralelo por canal)                       │
│  ├── Twitter/X → Threads + engagement                            │
│  ├── Instagram → Posts + Stories + Reels                          │
│  ├── TikTok → Vídeos curtos + trends                             │
│  ├── LinkedIn → Thought leadership                               │
│  ├── Reddit → Community engagement autêntico                     │
│  └── SEO → Conteúdo orgânico + link building                     │
│                                                                   │
│  FASE 4: ANÁLISE & OTIMIZAÇÃO                                    │
│  ├── Analytics Reporter → Dashboards + métricas                  │
│  ├── Growth Hacker → Otimização de funis                         │
│  └── Executive Summary → Report para stakeholders                │
│                                                                   │
│  ◆ Loop contínuo: Medir → Analisar → Otimizar → Criar           │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Marketing & Growth. Preciso lançar uma campanha 
para um novo produto SaaS B2B. 

Comece pela Fase 1: o Growth Hacker deve definir a estratégia de 
aquisição, o SEO Specialist deve fazer o keyword research para o 
nicho, e o Social Media Strategist deve planejar os canais 
prioritários (LinkedIn + Twitter para B2B).
```
