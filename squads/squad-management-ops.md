## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                SQUAD GESTÃO & OPS - WORKFLOW                      │
│                                                                   │
│  FASE 1: INICIAÇÃO & PLANEJAMENTO                                │
│  ├── Studio Producer → Visão, escopo e cronograma macro          │
│  ├── Senior PM → Breakdown de tarefas + resource planning        │
│  ├── Workflow Architect → Mapeamento de processos e fluxos       │
│  └── Legal Compliance → Riscos legais e requisitos de compliance │
│                                                                   │
│  FASE 2: EXECUÇÃO & COORDENAÇÃO                                  │
│  ├── Project Shepherd → Remoção de bloqueios + daily standups    │
│  ├── Studio Operations → Gestão de recursos e capacidade         │
│  ├── Experiment Tracker → Hipóteses, experimentos e resultados   │
│  └── Finance Tracker → Budget tracking + forecasting             │
│                                                                   │
│  FASE 3: MONITORAMENTO & CONTROLE                                │
│  ├── Analytics Reporter → KPIs, dashboards e alertas             │
│  ├── Senior PM → Status reports e gestão de riscos               │
│  ├── Legal Compliance → Auditorias periódicas                    │
│  └── Support Responder → Gestão de escalações                    │
│                                                                   │
│  FASE 4: ENCERRAMENTO & RETROSPECTIVA                            │
│  ├── Studio Producer → Post-mortem e lições aprendidas           │
│  ├── Executive Summary → Report executivo final                  │
│  ├── Infrastructure Maintainer → Handover e documentação ops     │
│  └── Workflow Architect → Otimização dos processos para o próximo│
│                                                                   │
│  ◆ Ciclo: Planejar → Executar → Monitorar → Ajustar             │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Gestão & Operações. Preciso estruturar a operação
de um projeto de transformação digital com 6 meses de duração e
múltiplas equipes envolvidas.

Comece pela Fase 1: o Studio Producer deve criar o charter do
projeto e o cronograma macro, o Senior PM deve fazer o breakdown
das workstreams e o Workflow Architect deve mapear os processos
atuais vs. futuros.
```
