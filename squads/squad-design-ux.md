## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                   SQUAD DESIGN & UX - WORKFLOW                    │
│                                                                   │
│  FASE 1: DESCOBERTA & PESQUISA                                   │
│  ├── UX Researcher → User interviews, personas, journey maps     │
│  ├── Product Manager → Objetivos de negócio + OKRs              │
│  ├── UX Architect → Arquitetura de informação + IA map           │
│  └── Brand Guardian → Análise de marca + guidelines              │
│                                                                   │
│  FASE 2: DESIGN SYSTEM & ESTRUTURA                               │
│  ├── UI Designer → Tokens, componentes, design system            │
│  ├── UX Architect → Wireframes + user flows                      │
│  ├── Brand Guardian → Identidade visual + paleta                 │
│  └── Inclusive Design → Acessibilidade desde o início            │
│                                                                   │
│  FASE 3: CRIAÇÃO & REFINAMENTO                                   │
│  ├── UI Designer → High-fidelity mockups                         │
│  ├── Visual Storyteller → Ilustrações + assets                   │
│  ├── Whimsy Injector → Microinterações + personalidade           │
│  ├── Image Prompt Engineer → Assets AI-generated                 │
│  └── Frontend Developer → Prototipação interativa                │
│                                                                   │
│  FASE 4: VALIDAÇÃO & ENTREGA                                     │
│  ├── UX Researcher → Testes de usabilidade                       │
│  ├── Accessibility Auditor → Auditoria WCAG                      │
│  ├── UI Designer → Handoff para dev (specs + assets)             │
│  └── Brand Guardian → Aprovação final de consistência            │
│                                                                   │
│  ◆ Loop: Design → Protótipo → Teste → Refinar                   │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Design & UX. Preciso criar o design completo de um
aplicativo de finanças pessoais para mobile e web.

Comece pela Fase 1: o UX Researcher deve definir as personas principais
e mapear os jobs-to-be-done, o UX Architect deve criar a arquitetura
de informação e o Product Manager deve alinhar os objetivos de negócio
com as necessidades dos usuários.
```

## 📊 Métricas de Sucesso

| Métrica | Target |
|---------|--------|
| SUS Score (Usabilidade) | > 75 |
| Task completion rate | > 85% |
| WCAG compliance | AA ou AAA |
| Design system coverage | > 90% dos componentes |
| Time-to-prototype | < 3 dias por feature |
| Brand consistency | 100% nos assets entregues |
