## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                    SQUAD TECH - WORKFLOW                          │
│                                                                   │
│  FASE 1: DISCOVERY & REQUISITOS                                  │
│  ├── Product Owner → Define visão, objetivos e escopo            │
│  ├── Workflow Architect → Mapeia todos os fluxos do sistema      │
│  ├── Technical Writer → Documenta requisitos e specs             │
│  └── UX Architect → Define arquitetura de informação             │
│                                                                   │
│  FASE 2: ARQUITETURA & DESIGN                                    │
│  ├── Software Architect → Decisões arquiteturais (ADRs)          │
│  ├── Backend Architect → Design de APIs e banco de dados         │
│  ├── UI Designer → Design System e componentes                   │
│  ├── DBA → Schema e estratégia de dados                          │
│  └── Sprint Prioritizer → Backlog priorizado (RICE)              │
│                                                                   │
│  FASE 3: DESENVOLVIMENTO (Sprints)                               │
│  ├── Frontend Developer → Implementação UI                       │
│  ├── Backend Architect → APIs e lógica de negócio                │
│  ├── Senior Developer → Padrões complexos e code review          │
│  ├── Mobile Developer → App nativo/cross-platform                │
│  ├── Code Reviewer → Review de PRs                               │
│  └── Scrum Master → Coordenação e remoção de impedimentos        │
│                                                                   │
│  FASE 4: QUALIDADE & DEPLOY                                      │
│  ├── QA Lead → Testes visuais e funcionais                       │
│  ├── API Tester → Validação de endpoints                         │
│  ├── Security Engineer → Auditoria de segurança                  │
│  ├── Reality Checker → Verificação final (Gate Keeper)            │
│  └── DevOps → CI/CD, deploy e monitoramento                      │
│                                                                   │
│  ◆ Dev↔QA Loop entre Fases 3 e 4 (max 3 retries por task)       │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Tecnologia. Preciso construir um sistema de e-commerce 
com as seguintes características:
- Frontend em React/Next.js
- Backend em Python/FastAPI
- Banco PostgreSQL
- Deploy com Docker no Coolify

Comece pela Fase 1: o Product Owner deve definir o escopo do MVP, 
o Workflow Architect deve mapear os fluxos principais (cadastro, 
carrinho, checkout, pagamento) e o Technical Writer deve documentar 
os requisitos.
```
