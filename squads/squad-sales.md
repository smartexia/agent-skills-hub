## 🔄 Workflow do Squad

```
┌──────────────────────────────────────────────────────────────────┐
│                    SQUAD SALES - WORKFLOW                         │
│                                                                   │
│  FASE 1: PROSPECÇÃO & TARGETING                                  │
│  ├── Outbound Strategist → ICP, segmentação e canais             │
│  ├── Sales Data Extraction → Enriquecimento de leads             │
│  ├── Pipeline Analyst → Scoring de leads + priorização           │
│  └── Sales Coach → Playbooks de abordagem                        │
│                                                                   │
│  FASE 2: DISCOVERY & QUALIFICAÇÃO                                │
│  ├── Discovery Coach → Metodologia de perguntas (SPIN/MEDDIC)   │
│  ├── Deal Strategist → Mapeamento de stakeholders                │
│  └── Sales Engineer → Validação técnica de fit                   │
│                                                                   │
│  FASE 3: PROPOSTA & NEGOCIAÇÃO                                   │
│  ├── Proposal Strategist → Proposta personalizada + ROI          │
│  ├── Sales Engineer → Demo técnica e POC                         │
│  ├── Deal Strategist → Estratégia de negociação                  │
│  └── Account Strategist → Multi-threading de stakeholders        │
│                                                                   │
│  FASE 4: FECHAMENTO & EXPANSÃO                                   │
│  ├── Deal Strategist → Táticas de fechamento                     │
│  ├── Account Strategist → Plano de onboarding + expansão         │
│  ├── Analytics Reporter → Win/loss analysis                      │
│  └── Executive Summary → Report de pipeline para liderança       │
│                                                                   │
│  ◆ Ciclo contínuo: Prospectar → Qualificar → Propor → Fechar    │
└──────────────────────────────────────────────────────────────────┘
```

## 💡 Exemplo de Ativação

```
Ative o Squad de Vendas. Preciso estruturar o pipeline de vendas
para uma solução SaaS B2B no mercado enterprise.

Comece pela Fase 1: o Outbound Strategist deve definir o ICP
(Ideal Customer Profile) e os canais de prospecção prioritários,
o Pipeline Analyst deve criar o modelo de scoring de leads e o
Sales Coach deve elaborar o playbook de abordagem inicial.
```
